# PrintQueue Project Plan

## Objective

Build a Java Swing desktop application that manages print and xerox shop jobs using digital tokens, live queue tracking, cost estimation, and operator controls.

## Users

| User | Responsibilities |
|---|---|
| Customer | Submit job, view token, queue position, cost, and status |
| Operator | Start, mark ready, complete, or cancel jobs |

## Modules

1. Customer job submission
2. Token generation
3. Cost estimation
4. Live queue
5. Operator controls
6. CSV storage
7. Reports

## Development Order

1. Create project structure
2. Create model classes
3. Create queue and billing services
4. Build customer job form
5. Build live queue table
6. Build operator controls
7. Add CSV storage
8. Add reports
