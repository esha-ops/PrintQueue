# UI Design

## Main Window

The main window contains a JTabbedPane with:

1. New Print Job
2. Live Queue
3. Shop Operator

## New Print Job

Fields:

- Customer name
- Phone number
- Service type
- Paper size
- Pages
- Copies
- Print mode
- Submit Job button
- Clear Form button
- Job status label

## Live Queue

A JTable displays:

- Token
- Customer
- Phone
- Service
- Pages
- Copies
- Paper
- Mode
- Cost
- Estimated time
- Status

## Shop Operator

Buttons:

- Start Current Job
- Mark Ready for Collection
- Mark Completed
- Cancel Current Job

A progress bar shows the current job status.
